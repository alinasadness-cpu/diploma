## 2. Инструменты

| Инструмент | Обоснование |
|------------|-------------|
| Java 11 | Язык разработки |
| Gradle | Сборка проекта |
| JUnit 5 | Фреймворк для тестов |
| Selenide | UI-тесты, автоматическое управление драйверами |
| REST Assured | API-тесты |
| Apache Commons DbUtils | Работа с БД |
| MySQL Connector | Подключение к MySQL |
| PostgreSQL Driver | Подключение к PostgreSQL |
| Allure | Формирование отчётов |
| Docker | Запуск СУБД и эмулятора банковских сервисов |
| Git/GitHub | Хранение кода и документации |

---

## 3. Риски

| Риск | Меры mitigation |
|------|-----------------|
| Docker не запускается | Использовать готовые образы, проверить права |
| Эмулятор банка нестабилен | Добавить retry и ожидания |
| Проблемы с драйверами браузеров | Использовать Selenide с WebDriverManager |
| Баги в приложении | Оформлять Issue в GitHub |
| Две СУБД | Настроить оба подключения, тестировать на обеих |

## 6. Окружение

- **SUT:** `aqa-shop.jar` (порт **8080**)

- **Браузер:** Chrome / Firefox
- **ОС:** Windows 10 / Ubuntu 18.04
- **Данные карт:** `gate-simulator/data.json`
  - APPROVED: `4444 4444 4444 4441`
  - DECLINED: `4444 4444 4444 4442`
